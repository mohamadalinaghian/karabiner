## Overview

This is a Karabiner keyboard remapping configuration for macOS. Karabiner is a keyboard customization tool that allows sophisticated key remapping through JSON-based complex modifications.

**Repository Structure:**
- `karabiner.json` — Main configuration file containing profiles and complex modification rules
- `assets/complex_modifications/` — Modular JSON files for organized keybinding rules
  - `vim_and_caps.json` — Vim-inspired navigation and language switching
  - `my-vim-preset.json` — Additional Vim-style bindings and Caps Lock behavior
- `automatic_backups/` — Timestamped backups (auto-generated by Karabiner)

## How to Test Changes

Karabiner automatically detects changes to `karabiner.json`. After editing:

1. Edit the JSON file in your preferred editor
2. Karabiner reloads automatically (check System Preferences > Karabiner-Elements to verify)
3. Test the keybindings in any application to confirm behavior

**Validating JSON:** Ensure the JSON is valid before Karabiner will load it:
```bash
jq empty /Users/ma/.config/karabiner/karabiner.json
```

## Key Architecture Patterns

### Rule Structure
Each rule contains:
- `description` — Human-readable rule name
- `manipulators` — Array of keyboard event transformations
- `conditions` (optional) — Filters like app bundle IDs or modifier states

### Common Manipulator Types
- **`to`** — Always-applied transformation
- **`to_if_alone`** — Applied if key is tapped (quick press)
- **`to_if_held_down`** — Applied if key is held beyond threshold
- **`parameters`** — Timing thresholds (in milliseconds)

### Key Remapping Patterns in This Config

**Dual-purpose keys:** Caps Lock acts differently based on tap vs. hold:
- Hold = Left Control (for Ctrl+key combinations)
- Tap = Fn key or language switch (F19)

**Sequence detection:** The jk → Escape rule uses variables (`vim_jk_sequence`) to detect key sequences:
1. Press 'j' → sets variable to 1
2. Press 'k' → checks variable, sends Escape, resets variable
3. Any other key → resets variable

**Application-specific rules:** Use `conditions` with `frontmost_application_if` to target specific apps (e.g., Safari-only Enter behavior).

### Modifier Syntax
- `"mandatory"` — Key must be pressed with this modifier
- `"optional"` — Key works with or without this modifier

## Current Configuration Summary

**Caps Lock & Enter:**
- Caps Lock: Hold = Ctrl, Tap = Fn (language switch)
- Enter: Tap = Shift+Enter (newline), Hold = Enter (submit)

**Vim Navigation (Ctrl+hjkl):**
- Ctrl+h/j/k/l map to arrow keys (left/down/up/right)
- Ctrl+e/b/d for end-of-line, beginning-of-line, delete-char

**Vim Mode Exit:**
- jk sequence (fast press j then k) → Escape

**Safari-Specific:**
- Separate Enter behavior for Safari app to handle form submission correctly

## When Editing

- Keep JSON valid; invalid syntax silently prevents Karabiner from loading the profile
- The `to_if_alone_timeout_milliseconds` parameter affects tap/hold detection (typically 200-300ms)
- Test rule interactions—multiple rules can fire for the same key; order matters
- Use `conditions` to prevent conflicts between apps or modes
- Variable-based sequences (jk → Escape) need explicit reset conditions to avoid sticky state

## Performance Notes

- Complex modifications are evaluated in order; place high-priority/frequently-used rules first
- Variable state persists until explicitly reset; sequences must clean up after themselves
- Condition checking (app detection, variable state) has negligible performance impact
